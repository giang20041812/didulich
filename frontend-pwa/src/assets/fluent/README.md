# Biểu tượng 3D

Ảnh 3D trong thư mục này lấy từ bộ **Fluent Emoji** của Microsoft (https://github.com/microsoft/fluentui-emoji),
giấy phép MIT (xem LICENSE.txt), thu nhỏ còn 192×192 và đổi sang WebP.

| File | Ảnh gốc |
| --- | --- |
| homestay.webp | House with garden |
| experience.webp | Camping |
| transport.webp | Bus |
| combo.webp | World map |
| nearby.webp | Round pushpin |
